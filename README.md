# IoT Laser Tag

**[Download the complete prepared project](project-source.zip)** — extract this archive to restore the original project folder structure. Key source and report files are also available below for browsing.

A two-player infrared tag game using ESP32-S3 devices, MQTT events, LED health indicators, and a Node-RED dashboard.

## Technologies

MicroPython / ESP32-S3 / MQTT / Node-RED

## Explore the project

Configure the Wi-Fi and broker placeholders in Player1.py and Player2.py. Deploy each script as main.py on its corresponding board. The Node-RED flow export was not supplied; consult the converted setup manual for the original dashboard setup.
